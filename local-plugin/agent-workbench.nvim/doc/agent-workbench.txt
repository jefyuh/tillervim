*agent-workbench.txt*  Embedded agent terminals and chats

                                                        *agent-workbench*
Neovim 0.12.5+. require("agent_workbench") is inert; setup(opts) runs once.
Native terminal is built in. Snacks is optional and explicitly selected.
Native kinds are codex, antigravity, kimi and opencode. Each enabled kind
owns one terminal session. In TillerVim, select native and ACP entries
independently in tillervim.json. For example, kimi enables the interactive
CLI and kimi-acp enables a CodeCompanion chat using the same executable.

Codex provides the external prompt editor, native review hooks and transcript
reader. The other TUIs manage history and model selection in their CLI.
Select an ACP chat to use integrated round review with those agents.

:AI                  Switch chat
:AI new              New native/ACP/API entry, as configured by the host
:AI info             Providers, billing, open chats and HTTP profile
:AI key [name]       Switch the live HTTP profile (optional integration)
:AIInfo              Same information as :AI info

Public Lua operations, supported options, terminal contract and independent
lazy.nvim example are documented in README.md shipped beside this help file.

  require("agent_workbench").open("codex")
  require("agent_workbench").send_context("codex", {text = "draft"})
  require("agent_workbench").hide("codex")
  require("agent_workbench").show("codex")
  require("agent_workbench").stop("codex")

Hide keeps the session; stop tears it down. Sending context never submits it.
